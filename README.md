# AI 产品经理面试手册

一个自包含的单文件学习页面：59 个 AI 术语的面试口径、三张系统架构图、12 组高频辨析、6 个常见追问的答题骨架。

**直接双击 `AI产品经理面试手册.html` 就能在浏览器里打开**，没有构建步骤，没有依赖。

## 文件

| 文件 | 说明 |
|---|---|
| `AI产品经理面试手册.html` | 页面本体。CSS 和 JS 都内联在里面，约 1200 行 |
| `AGENTS.md` | 给 AI 编码助手（Codex / Claude Code）的改动约定。**动手改之前必读** |
| `check_handbook.py` | 17 项自检脚本，改完跑一遍 |

## 改完必须验证

```bash
python3 check_handbook.py
```

如果这次是**纯文案打磨**（只改文字、不动设计），用这个模式：

```bash
python3 check_handbook.py --copy-only
```

它会跟 git HEAD 逐项比对，硬性确认 CSS、JS、三张 SVG 架构图和整个 DOM 骨架一字未动。

脚本会检查标签闭合、三套主题变量是否同步、术语卡结构、编号连续性、SVG marker id、图内文字是否越界或压字、有没有混进外部 CDN 等。全绿之后再在浏览器里确认深色模式、375px 窄屏、背诵模式开关三件事。

## 页面上的功能

- **搜索框** —— 中英文都能搜，按 `/` 快速聚焦，`Esc` 清空
- **背诵模式** —— 打开后术语只剩英文和中文，点卡片展开答案
- **深色模式** —— 跟随系统
